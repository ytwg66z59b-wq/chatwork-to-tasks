# Toタスク（Chatwork Toメンション管理）

Chatworkのトーク履歴（Googleスプレッドシートに自動転記したもの）から、自分宛ての **To** だけを取り出してタスク一覧にするWebアプリです。

- 未対応のToがいちばん上。並び順は「未対応 → 時系列 → 宛先の名前順」
- 宛先がREで返信すると自動で「対応済み」。REを使わず、同じルームで送り主にToを返した場合も対応済みとみなします
- 自動判定で拾えないものは「完了にする」で手動で消せます（この端末のブラウザにだけ保存）
- 宛先・トークルーム・対応状況・キーワードで絞り込み。トークルームごとにまとめて表示も可
- 2分ごと、または画面に戻ってきたときに自動更新（スプレッドシート側は5分ごとに更新）

## しくみ

```
Chatwork ──(5分ごと)──▶ Googleスプレッドシート「ログ」
                               │
                    Apps Script の doGet（APIキー必須）
                               │  To抽出・返信判定をして JSON を返す
                               ▼
                 GitHub Pages の画面（このリポジトリ）
```

トーク本文はこのリポジトリには含まれません。画面は、APIキーを知っている人だけが読めるApps ScriptのAPIからデータを取ってきます。

## セットアップ

### 1. Apps Script を更新する
1. トーク履歴のスプレッドシートで「拡張機能 → Apps Script」を開く
2. 既存のコードを `gas/Code.gs` の内容で**丸ごと置き換えて**保存
3. 関数 `makeApiKey` を1回実行 → 実行ログに表示される `API_KEY` を控える
4. 「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押して、表示される **ウェブアプリのURL**（`…/exec`）を控える

> 以降に `Code.gs` を変更したときは「デプロイを管理 → 編集 → バージョン：新バージョン」で更新すると、URLはそのまま使えます。

### 2. 画面を開いて設定する
公開したページを開き、歯車アイコンから「ウェブアプリのURL」と「APIキー」を入れて保存します。

スマホに設定をそのまま渡したいときは、次の形のURLを自分宛てに送って開くと、自動で設定されます（開いたあとURLからは消えます）。

```
https://<ユーザー名>.github.io/<リポジトリ名>/#api=<ウェブアプリのURL>&key=<APIキー>
```

`?demo=1` を付けると、架空のデータでデモ表示できます。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 画面（ビルド不要の静的ファイル） |
| `demo.json` | デモ用の架空データ |
| `gas/Code.gs` | スプレッドシートへの転記 ＋ To一覧API（Apps Script） |

## 補足
- 送信者のIDは、この版から「ログ」シートのH列（送信者ID）に記録されます。それより前の行は、本文中の `[To:ID]名前さん` から名前とIDの対応を推測して判定しています。
- `[toall]`（全員宛て）はタスクにしていません。
